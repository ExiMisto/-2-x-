# 尖塔内开发版试玩

安装到 D:/steam/steamapps/common/Slay the Spire 2/mods/SpireTerrariaNextProbe/，与旧版 SpireTerraria 分开。在尖塔 Mod 设置中只启用 **BaseLib** 与 **泰拉瑞亚 × 杀戮尖塔 2**，关闭旧版及其他 Mod，重启后开启新的单人远征。

当前适配 Terraria 1.4.5.8、尖塔 v0.111.0，依赖 **BaseLib v3.4.7 或更新版本**。Terraria 需安装在尖塔同级目录，本机保留 XNA 4 和 .NET Framework 4。BaseLib 接管原生角色与物品模型；泰拉逻辑继续在独立 x86 worker 中运行，未退回旧桥接。

## 流程与操作

在尖塔原生选角页选择战士、射手、法师或召唤师，确认后直接以对应职业开始远征。普通角色不受融合模式接管。沿原生地图选择路线，普通战斗按阶段随机分波刷怪，精英和 Boss 使用泰拉敌人与独立建筑布局；胜利后通过尖塔界面选择装备或材料。

起始装备与旧版进度对齐：职业武器、木套装、手榴弹、三件移动／再生饰品、治疗药水和魔力药水。召唤师同时携带雀杖与皮鞭。真实装备牌组、饰品栏和药水栏与远征装备数据同步，不再用原版卡牌、遗物或药水借壳。

| 输入 | 功能 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| 空格 / W / 向上 | 跳跃 |
| 鼠标左键 | 向鼠标方向攻击 |
| S / 向下 | 下穿单向平台 |
| 1 / 2 / 3，或武器图标 | 切换三个武器槽 |
| 4 / 5 / 6，或投掷物图标 | 选择投掷物，再左键投掷，不占武器槽 |
| Q | 快捷投掷 |
| H / J | 使用治疗／魔力药水 |
| 原生药水栏 | 点击药水后选择使用；原生核心确认消耗后才移除瓶子 |
| P，或暂停按钮 | 暂停／继续 |
| 右上角 ↩ | 调试：保存当前生命与消耗，回到本房间原版卡牌战斗 |

战斗期间屏蔽尖塔快捷键并暂停其战斗节点；结束或取消后恢复。窗口失焦时暂停。点击场景上方的按钮不会同时挥动武器。

伤害数字直接显示泰拉原生结算：普通命中、暴击、持续伤害及玩家受伤均使用对应文字与样式。将鼠标移到尖塔饰品栏、商店饰品或宝箱饰品上，可查看具体数值、触发条件和组合限制；战斗中同样保留原生悬浮框。

火堆有四项：休息、强化 +20%、材料锻造、免费重铸。前三项共享一次主行动；重铸每个火堆共享三次，可在主行动之后继续使用。锻造先查看材料成本与产物范围，扣料后固定随机三选一；取消替换时保留待领取结果。

商店卡牌为装备、白色卡牌为投掷物、遗物为饰品、药水为泰拉药水。购买武器或防具后更新真实装备牌组，投掷物进入独立库存；删牌服务当前不执行。宝箱直接展示泰拉饰品选择，并加入原生饰品栏。事件与远古之民选项影响泰拉材料或生命。

## 数据与限制

装备与材料存于安装目录 state/profile-{id}/ 的独立 JSON，按远征种子、开始时间、角色与档案区分。包含奖励缓存、主行动与重铸次数、待选择结果；写入使用临时文件替换。读取失败会保留原文件并停止该次接管，日志中显示错误。现有测试覆盖模型保存和奖励序列化恢复；真实退出续玩尚未全面验收，建议只开测试新局。

饰品突破泰拉原生槽位限制，当前战斗配置上限 64 件；重复饰品转材料。尖塔药水栏保留正常槽位上限，额外药水存于远征补给库存，空位出现后补入。强化采用基础值加算，工程上限为 +1000。当前没有证明全部原版饰品及特殊武器机制均正确。

三幕生命上限 300 / 600 / 900；装备与怪物数值仍待整局平衡。六种 Boss 仅有启动与一定时长的原生 AI 检查，没有各职业完整击败全部 Boss 的通关记录。物品图标通过独立接口读取本机真实纹理，并用于选角、装备奖励与库存。场景仍由自写合成器绘制，复杂人物装备、Boss 特效、光照与原生音效转发尚未全面完成。

## 重建和隔离自测

~~~powershell
$taskPwsh='C:/Users/ExiMisto/.cache/codex-runtimes/codex-primary-runtime/dependencies/native/powershell/pwsh.exe'
& $taskPwsh -NoProfile -File tools/Build-Spire.ps1 -Install
& $taskPwsh -NoProfile -File tools/Test-Spire.ps1 -Adventure -TimeoutSeconds 240
~~~

自测临时只启用 BaseLib 与新版 Mod，启动实际图形游戏，使用原生 MockGodotFileIo 内存存档。验收脚本通过原生选角、启程和药水菜单回调检查职业、战斗、真实库存、奖励、火堆、商店、宝箱、事件及地图暂停。火堆材料是明确的测试夹具，不代表自然掉落经济或人工操作已经验收。本轮图形旅程状态见 [M3-VALIDATION](M3-VALIDATION.md)。

结束后恢复原有 Mod 开关。报告、日志和 viewport 图片位于 .local/spire-test/，前次结果按运行归档。若恢复中断，先关闭游戏，再运行 tools/Test-Spire.ps1 -RestoreOnly。脚本只回收自己启动的游戏进程。旧基础接入回归可不带 -Adventure 运行；它仍固定为附魔剑对蓝史莱姆，仅用于检查旧的基础通信入口。
