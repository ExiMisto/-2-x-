# M0 本机验证

2026-10-21，Windows x64、Terraria 1.4.5.8。`tools/Test.ps1` 已完成 41 项检查，机器可读结果在 `.local/verification.json`。

## 已实际运行

- 64 位客户端启动独立 32 位工作进程，经本用户权限的命名管道通信；会话凭证通过标准输入传递。
- 工作进程直接加载本机 `Terraria.exe`，按需从原程序内存资源或本机游戏目录解析依赖；不使用旧版 Mod 或 TerrariaICEY 运行库。
- 读取原生 Main、Player、Item、NPC、Projectile、ItemID 的 API 信息；返回真实的木剑、泰拉刃、天顶剑和弩车魔杖 ID。
- 设置项目独立运行路径，按原生初始化顺序调用 `Item.SetDefaults`，读取装备属性。该过程没有创建图形窗口，也没有开始战斗。
- 错误协议、超大帧、负长度、缺失数据、错误凭证、握手前请求、重复序号、错误消息方向均被拒绝。
- 未知物品与非法请求正文返回错误，进程仍可响应后续合法请求；缺失游戏目录时返回请求错误。
- 正常退出、宿主断连、工作进程崩溃与无响应超时经过检查；测试后没有残留的工作进程。超时检查使用明确标记的测试进程，不以它代替真实游戏访问验证。
- 测试前后 `Terraria.exe` 和已安装的旧版 `SpireTerraria.dll` 哈希一致。

## 当前边界

本页 41 项检查只验证进程通信、恢复路径与原生装备访问。战斗与帧传输的后续实测单独记录在 [M1-VALIDATION.md](M1-VALIDATION.md)；原生音效、尖塔选路接入和远征保存仍未完成。

新实现的代码只在本机；原游戏与旧 Mod 未替换，未向仓库上传新版本。
