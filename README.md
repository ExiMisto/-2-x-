# 泰拉瑞亚 × 杀戮尖塔 2

**四职业实时远征，开发版 v0.4.0。** 在杀戮尖塔 2 的地图上选路，进入房间后使用泰拉瑞亚原生角色、武器和敌人战斗；战后沿用尖塔界面选择装备、购买补给、开箱和处理事件。

本仓库保存宿主 Mod、原生战斗扩展、装备目录及构建工具的源码。原生桥接依赖单独安装的 [TerrariaICEY](https://github.com/Hatsunetrump/TerrariaICEY)，固定版本见 [upstream.json](upstream.json)。仓库不含游戏本体、原生桥接二进制、提取的游戏素材、个人存档、录制文件或安装压缩包。

## 已实现

- 战士、射手、法师、召唤师四个角色，分别使用本职业装备池。
- 原版分支地图；普通、精英与 Boss 房间按幕切换敌人池，普通场地较小、Boss 场地较大。
- 131 条装备配置，含 88 把武器与 43 套护甲，按肉前、机械三王前、月前阶段分配，并区分普通、罕见、稀有。
- 三武器槽与一套护甲；获得第四把武器时选择替换，可取消。
- 单件装备锻造 `+1`、`+2`……，每级增加其原始伤害或基础防御的 20%，采用加算，仅对该件装备生效。
- 三幕最大生命为职业初始值的 1 / 2 / 3 倍，升幕保留已损失的生命；生命不进入战后装备池。
- 商店卡牌出售武器和护甲，遗物位出售饰品，药水位出售药水；通用爆破消耗品不占武器槽。
- 宝箱直接提供泰拉瑞亚饰品，事件和远古选项影响实际装备与物资。
- 饰品通过独立列表生效，突破原版功能槽数量限制；当前协议上限 256 件，重复件与跑鞋链做去重处理。
- 十二件酒馆哨兵武器及相关护甲、饰品保留；已取消远古之民塔防、水晶与波次等待。
- 换房间清理掉落、弹幕和残留特效。实时战斗期间屏蔽尖塔键盘动作，非战斗界面恢复原版输入。

## 运行与操作

已验证环境：Windows、Slay the Spire 2 **v0.111.0**、BaseLib **v3.4.7**、Terraria **1.4.5.8**。两款游戏位于同一个 Steam `common` 目录，构建后安装至 `Slay the Spire 2/mods/SpireTerraria`，无需另开泰拉瑞亚窗口。

从单人角色选择页选择泰拉瑞亚职业并开始游戏。

| 操作 | 按键 |
| --- | --- |
| 移动 / 跳跃 / 下平台 | A、D 或方向键 / 空格、W / S |
| 瞄准与攻击 | 鼠标、左键 |
| 三把武器 | 1、2、3 |
| 手榴弹、炸弹、雷管 | 4、5、6 选中，左键投掷 |
| 治疗 / 魔力药水 | H / J，也可操作顶部药水栏 |
| 暂停 | P，失焦或打开覆盖界面也会自动暂停 |

爆炸可能伤到自己。药水从尖塔药水栏消耗，跨房间保留当前生命和投掷物数量。

## 开发

构建步骤见 [docs/BUILDING.md](docs/BUILDING.md)，历史验证范围见 [docs/VALIDATION.md](docs/VALIDATION.md)。装备的原生 ItemID、职业、阶段与稀有度见 [content/equipment.json](content/equipment.json)。

本版只支持单人，远征不写入持久存档，不能中途继续；联机、完整开放世界、读取玩家 `.wld`、全生态群落场地、原生音效转发尚未实现。数值与经济仍需完整跑局调整，尚未验证三幕完整通关和全部装备的长期实战表现。非战斗动画与部分地图标记仍复用宿主资源。

运行日志会在 Mod 安装目录按需生成。调试入口仅在明确创建对应请求文件时触发，正常游玩不会自动录制或进行测试。
