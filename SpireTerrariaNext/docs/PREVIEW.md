# 独立战斗预览

这是 M1 的手动游玩验收窗口。它与旧 Mod 分开运行，不替换尖塔 `mods/` 内容；目前只有平地上的蓝史莱姆试炼，尚未接入尖塔角色选择、地图、奖励和存档。

先构建工作进程，再由玩家显式打开预览：

```powershell
pwsh -File tools/Build.ps1
pwsh -File tools/Preview.ps1
```

预览顶部可以选择附魔剑、木剑或水矢。更换武器会先结束当前场地，再创建新的场地。每次场地使用独立 GUID 会话。

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或左 / 右方向键 |
| 跳跃 | 空格、W 或上方向键 |
| 瞄准、攻击 | 移动鼠标、按住左键 |
| 暂停、继续 | P |
| 重新开始 | R |
| 关闭预览 | Esc |

窗口失焦时会清空输入并暂停。切回后需要明确按 P 继续。暂停与战斗结束时仍每五秒维持连接。生命、敌人生命和胜负来自原生战斗状态；重开会清理上一场地，关闭窗口会请求结束并回收工作进程。

画面是工作进程真实绘制后通过共享内存传来的 640×360 BGRA 图像。宿主使用整数倍最近邻放大并保留黑边，不录桌面和其他屏幕。当前瞄准映射与 M1 的固定场地/相机规则一致；后续相机规则变化时需要同步升级控制状态。

当前主窗口仍同步等待工作进程，最长可等待现有协议的五秒超时。这是开发预览的限制。异常会显示重试/安装检查提示，可以按 R 重试。原生图形资产来自本机合法安装的泰拉瑞亚，不包含在宿主程序里。

只编译宿主，不启动窗口或修改工作进程：

```powershell
pwsh -File tools/Preview.ps1 -BuildOnly
```

开发者可运行约二十秒的检查：先暂停十七秒、每五秒维持连接，再进行约三秒真实战斗，自动保存预览控件的画面与结果后关闭：

```powershell
pwsh -File tools/Preview.ps1 -SmokeTest
```

输出位于 `.local/preview-test/host-preview.png` 和 `result.json`。检查使用隐藏的自有窗口，截图仅调用本窗口渲染控件的 `DrawToBitmap`，不会截取桌面或另一台显示器。检查包含超过空闲期限的暂停保活、恢复后至少六十个真实更新或胜利、状态与共享帧配对，以及退出后的工作进程回收；不等同完整跑局验证。正常手动预览才会显示交互窗口。

预览使用 Stopwatch 累积时间，以每秒六十次原生更新步进；计时器一次回调最多补四步，长时间卡顿会丢弃过量补步。暂停、失焦与重新开始均清空累计时间，避免恢复时突然追赶。

本机首轮检查已实际通过：暂停 17.03 秒、收到三次保活响应且 tick 未变；恢复后约三秒内运行 118 个原生 tick，敌人生命降至 2。画布截图已人工查看，内容为原生角色、史莱姆与地面，退出后预览及工作进程均已回收。启动后的首次加载与卡顿会触发补步上限，因此这不代表已经保证每秒六十次的持续性能。自动检查使用程序输入；键盘、鼠标与完整长时间游玩仍可通过正常预览窗口人工体验。
