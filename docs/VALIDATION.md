# v0.4 验证范围

本记录归纳 2026-10-20 在 Windows、本地 Terraria 1.4.5.8、Slay the Spire 2 v0.111.0 与 BaseLib v3.4.7 下的开发测试。清理工作区后不保留原始截图、日志、反编译文件和个人存档备份；以下为历史结果摘要，不是仓库内可独立复核的完整测试证据。

- 原生回归 166 项通过，测试清怪调用 0。覆盖四职业样本真实战斗、装备目录约束、独立锻造、三幕生命、随机遭遇、投掷物、跨房间物资与清理、药水、十件饰品同时生效和哨兵兼容。
- 正式宿主完整旅程 21 项通过：四职业选角、召唤师两场地图战斗、两次装备奖励、商店、宝箱与事件。实际累计伤害 407，测试清怪 0，远征 `shouldSave:false`。
- 最终经济界面独立复测 16 项通过，覆盖商店替换取消与确认、护甲、药水、饰品、宝箱和事件锻造。
- 三个被跟踪的宿主进度文件哈希前后相同，没有通过恢复备份覆盖测试后的文件。

验证的是固定样本。没有完成三幕完整自然通关、全部职业对全部 Boss 的胜负测试或 131 条装备的逐件长期实战；职业、经济与首领难度仍需平衡。

四类 T1 酒馆哨兵已在普通房间真实放置并命中敌人；T2 / T3 弩车验证了放置、独立锻造与切换后伤害保持，其他 T2 / T3 尚未逐件做同等检查。塔防、水晶与波次已移除。

历史宿主退出时曾记录 Godot `Invalid Task ID`，原生 JIT 也有部分跳过提示。通过上述检查不代表没有引擎警告。

验证工具仍在 `tools/` 和 `src/` 中，可按 [BUILDING.md](BUILDING.md) 重新生成本机日志。测试需要本地正版游戏与图形设备。
