
# 泰拉瑞亚 × 杀戮尖塔 2

**在尖塔里选路，在泰拉里开打。**

选择战士、射手、法师或召唤师，沿《杀戮尖塔 2》的分支地图前进。走进战斗房间，就用泰拉瑞亚角色、武器和弹幕迎战；战后回到尖塔熟悉的奖励、商店、宝箱、事件和火堆，组出属于这一局的装备流派。

当前为 **Next 独立核心的 Windows 单人开发版**。新版源码位于 **[SpireTerrariaNext/](SpireTerrariaNext/)**，旧版 Classic 源码保留在仓库原位置供历史对照。开发或构建新版时请进入 Next 目录，不要混用根目录的旧版构建工具。

## 一局怎么玩

### 四个职业，三幕成长

战士挥剑、射手倾泻弹幕、法师释放魔法、召唤师带召唤物与鞭子出战。装备池按职业筛选，武器和护甲依照泰拉成长阶段分散在三幕中，并分普通、罕见、稀有。

同时携带三把武器，拿到第四把时选择替换。防具按整套装备；手榴弹、炸弹、雷管等通用投掷物使用独立库存，不占武器槽。三幕生命上限为 300 / 600 / 900。

### 现在变强，还是赌下一幕？

战斗奖励提供两件装备和一个随机材料包。已有和近期出现的装备会降低重复权重。选择材料，意味着放弃眼前的装备，为后续的火堆锻造留资源。

矿锭、织物、骨片、晶体与精华分幕掉落。品质越高，配方需要的材料种类越多；配方按本局固定随机，支付后从三件产物里选一件，也能用本幕材料提前锻出下一幕的普通入门装备。

### 火堆不只用来回血

休息、单件强化和材料锻造共享一次火堆主行动。另有 **三次免费重铸机会，在全装备之间共享**：随机得到新词条后，可以采用，也可以保留旧词条；这次机会仍会消耗。

武器词条影响伤害、暴击、攻速或魔耗，护甲词条影响防御或移速。单件强化保留 `+1`、`+2`……，每级增加该件基础伤害／防御的 20%，采用加算，替换装备不继承。

### 尖塔的取舍，泰拉的战利品

- **商店：** 卡牌位买武器／防具，遗物位买饰品，药水位买泰拉药水，白色卡牌位买通用投掷物。
- **宝箱：** 直接领取泰拉饰品，使用尖塔饰品栏和获得动画。
- **精英与 Boss：** 克眼对应克苏鲁护盾、史莱姆王对应皇家凝胶等，按其原版饰品来源抽取；没有专属饰品或全部已持有时改给材料。
- **事件与远古者：** 各九种主题，影响装备、材料、金币、生命、单件强化与词条，不只是重复发同一种奖励。
- **饰品与药水：** 保留尖塔原生栏位和具体效果提示。饰品突破泰拉原版功能栏数量限制，当前战斗配置上限 64 件；额外药水进入补给库存，空位出现后补入。

### 房间也有自己的样子

普通战斗在林间哨站、废弃矿井、腐化祭坛等建筑中进行，分波刷出当前阶段敌人；Boss 有王庭、工厂、丛林祭殿、风暴港口等专用场地。普通场地较小，Boss 场地较大，低平台与越界回收减少掉落卡关。

场地使用本机泰拉方块、墙和平台纹理搭建，属于独立竞技场，不读取玩家世界。旧日军团装备和哨兵继续可用，**没有塔防水晶或等待波次的塔防模式**。

战斗保留尖塔顶栏、血条、饰品栏和药水栏，并显示泰拉伤害跳字。实时战斗期间屏蔽尖塔卡牌快捷键；失焦、暂停或打开地图时暂停战斗，结束后恢复原版输入。

## 安装与操作

当前验证环境：Windows、《杀戮尖塔 2》**v0.111.0**、Terraria **1.4.5.8**、**BaseLib v3.4.7 或更新版本**，另需 .NET Framework 4 与 XNA 4。

两款游戏应位于同一 Steam 库的 `common` 目录。新版从本机读取游戏程序和素材，不需要另开泰拉窗口；不将 TerrariaICEY 作为新版运行前置。BaseLib 仍需单独安装。

本仓库提供源码。按 **[新版构建与安装指南](SpireTerrariaNext/docs/BUILDING.md)** 构建后，将整个 `SpireTerrariaNextProbe/` 输出目录安装到尖塔 `mods/`，保留更新前的 `state/`。只启用 BaseLib 与新版融合 Mod，关闭旧版 SpireTerraria，重启后在原生选角页选择泰拉职业开启测试新局。

| 操作 | 按键 |
| --- | --- |
| 移动／跳跃／下穿平台 | A、D 或左右方向键／空格、W／S |
| 瞄准、攻击 | 鼠标、左键 |
| 三个武器槽 | 1、2、3 |
| 通用投掷物 | 4、5、6 选中后左键；Q 快捷投掷 |
| 治疗／魔力药水 | H／J，也可点击原生药水栏 |
| 暂停 | P |

详细操作和数据位置见 [试玩说明](SpireTerrariaNext/docs/SPIRE-PROBE.md)。
